## 项目简介

> （此处为中文简介初稿，机主可按自己想法直接修改）
>
> **ScreenCoverLock** 是一款轻量级、纯本地运行的 Windows 全屏桌面遮屏锁定工具。
> 它提供自定义全屏壁纸、闲置自动暗屏、逐位密码检测、可选本机摄像头异常录像，以及带真人输入保护的自动化临时暂停接口。

---

## 核心特性

- **双运行模式**
  - **严格模式（`ScreenCover-Strict.exe`）**：置顶全屏遮罩，持续保持焦点，拦截 `Win` 键、`Alt+F4` 与 `Ctrl+Shift+Esc` 等常见切窗热键。
  - **日常模式（`ScreenCover-Casual.exe`）**：轻量遮屏覆盖，不强制反复抢占焦点，适合日常临时离开使用。
- **多显示器全覆盖**
  - 自动监听显示器插拔与分辨率变化，为每个副屏同步创建全屏遮罩窗口。
  - 主屏负责密码输入与视觉反馈，副屏同步切换正常图与暗图。
- **闲置自动变暗**
  - 无本地真人键鼠操作达到设定时长（默认 `10` 秒）后自动切换至暗图。
  - 移动鼠标、开始输入或输入正确密码前缀时保持暗屏，仅在出现错误字符时恢复正常图并提示。
  - 不修改 Windows 系统屏幕亮度。
- **界面图片完全可替换（零版权风险设计）**
  - 开源仓库默认内置的所有壁纸、输入指示图标、警示图标与程序图标均为程序生成的**极简无版权几何图形**。
  - 支持在设置界面将各界面图片替换为任意本机图片，仅保存在本机运行，不进入代码仓库。

## 界面图片自定义说明

点击设置入口（`--settings`）并验证机主密码后，可自由替换以下界面元素：

1. **正常背景图（Normal Image）**
   - 遮屏启动与正常输入状态下显示的全屏壁纸（按比例铺满屏幕）。
2. **暗图（Dark Image）**
   - 闲置超时后切换的暗色壁纸。
   - **智能自动变暗**：如果只设置了“正常背景图”而将“暗图”留空，程序会自动基于你的正常背景图生成低亮度版本，不会跳回默认图。
3. **密码输入进度图标（1～5 位 & 第 6 位完成图标）**
   - **输入图标目录**：选择包含自定义图标的本地文件夹，自动按顺序匹配 `1.png`～`5.png`（或 `digit-1.png`～`digit-5.png`）。
   - **单张输入图标（备选）**：未指定目录或缺少对应序号时，可使用同一张图标表示 1～5 位输入长度。
   - **输满 6 位图标**：输入第 6 位字符时显示独立完成图标（也可在图标目录中放置 `6.png` 或 `complete.png` 自动识别）。
   - *注：输入图标仅反映已输入字符个数，不泄露任何密码正确性信息。*
4. **错误提示图（可选）**
   - 可选配置自定义错误警示图片，并勾选“输入错误时显示错误提示图”开关决定是否展示。
5. **输入指示区位置**
   - 支持选择 `Bottom`（底部居中，默认）、`Center`（屏幕正中）或 `Top`（顶部居中），适配不同构图的自定义壁纸。
6. **一键预览与清除**
   - 每项图片设置均支持即时弹窗预览，点击“清除”即可一键恢复为内置默认无版权图形。

## 密码机制与安全保护

- **首次设置**：首次运行或打开 `--settings` 时在本机设置 6 字符机主密码。
- **逐位前缀检测**：
  - 使用当前 Windows 用户的 **DPAPI**（`DataProtectionScope.CurrentUser`）加密保存密码校验资料与随机密钥 `HMAC-SHA256` 前缀校验值。
  - 磁盘上**不保存**明文密码或明文前缀。
- **输入与防试错规则**：
  - 退格删除不算错误；单独修饰键不触发错误；大小写敏感；禁用输入法（IME）与粘贴快捷键。
  - 输入任意错误字符时立即显示提示文字（可关闭），60 秒无编辑自动清空当前输入尝试。
  - 连续 5 次提交错误后进入 30 秒冷却锁定。
  - 完整输入 6 位密码并按 `Enter` 解锁；`Escape` 清空当前尝试；`Ctrl+Shift+Q` 应急退出。

## 可选本机异常录像（默认关闭）

- **隐私与默认关闭**：录像功能默认完全关闭，必须由机主在设置界面手动选择摄像头、完成约 3 秒画面测试并确认拍摄范围后，才能勾选启用。
- **触发条件**：
  - 输入任意错误密码字符（若同一尝试中退格纠正并最终正确解锁，将自动取消并清理仅含该次尝试的片段）。
  - 本机物理键盘触发 `Ctrl+Shift+Q` 应急退出。
  - 可选开启明确的本机鼠标操作触发（默认关闭，过滤微小抖动）。
- **独立编码进程**：
  - 由独立进程 `ScreenCover.Recorder.exe` 调用本地 `tools/ffmpeg.exe` 录制无音轨 H.264 `.mkv` 视频。
  - 确认首帧后默认录制至末次触发后 15 秒，单段最长 60 秒；支持在设置页查看事件、播放录像、删除单条或按天数/容量自动清理。
  - 全程纯本机存储，**不提供任何云端上传功能**。

## 自动化临时暂停控制（可选）

适合需要后台脚本或自动化工具在机主离开时短暂操作桌面的场景：

- 仅当启动时显式传入 `--allow-automation` 且机主在弹窗中点击**“是”**后才会启用。
- 通过限定当前用户 SID 与当前 Windows 会话的命名管道（`ScreenCover-Control.ps1`）通信：
  - 支持 `Status`、`Start`、`Renew`、`Resume` 命令与租约自动续期。
  - **真人物理输入立即恢复**：暂停期间挂载 `InputGuard` 底层键鼠钩子，一旦检测到非注入的本机物理键鼠操作，立即拦截并恢复全屏遮屏。
  - `Ctrl+Shift+L` 可随时手动立即恢复遮屏。

## 快速构建与运行

### 环境要求

- Windows 10 / 11（x64）
- Windows 自带 .NET Framework 4.x 编译器（`csc.exe`，无需额外安装 Visual Studio）
- PowerShell 5.1+

### 编译与测试

```powershell
# 1. 编译 Strict / Casual / Recorder 及测试程序
.\build.ps1

# 2. 运行核心逻辑与布局测试（不启动全屏遮屏，不调用摄像头）
.\tests\out\UpgradeTests.exe
.\tests\out\ControlTests.exe

# 3. （可选）如需启用本机摄像头录像，下载官方 FFmpeg essentials 至 tools/ffmpeg.exe
.\scripts\Download-FFmpeg.ps1

# 4. （可选）打包独立单文件安装程序到 dist/
.\scripts\Build-Package.ps1 -Version 1.1.0
```

### 运行入口

- 打开设置与自定义图片：`.\out\ScreenCover-Strict.exe --settings`
- 启动严格模式：`.\out\ScreenCover-Strict.exe`
- 启动日常模式：`.\out\ScreenCover-Casual.exe`
- 如需允许本地自动化控制，请附加 `--allow-automation` 参数。
